Kebijakan Privasi RoadPulse

Berlaku sejak {{ effective_date }}

RoadPulse adalah aplikasi pendataan kerusakan jalan. Kebijakan ini menjelaskan data apa yang kami kumpulkan saat Anda memakai dashboard web dan aplikasi mobile RoadPulse, untuk apa data itu dipakai, dan hak Anda atas data tersebut, sesuai Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi.

1. Data yang kami kumpulkan

  • Akun: username dan kata sandi. Kata sandi disimpan dalam bentuk terenkripsi (hash) dan tidak dapat dibaca oleh siapa pun, termasuk pengelola.
  • Foto jalan yang Anda ambil atau unggah, beserta hasil analisisnya (jenis kerusakan dan tingkat keyakinan).
  • Lokasi: koordinat GPS dan nama lokasi saat foto diambil, bila Anda memberikan izin lokasi. Foto tetap dapat dianalisis tanpa lokasi.
  • Waktu pengambilan dan pengiriman foto.
  • Alamat IP, dipakai sementara untuk membatasi percobaan masuk dan pendaftaran demi keamanan, serta tercatat di log server.

2. Tujuan penggunaan data

  • Mengenali jenis kerusakan jalan dari foto dan menyimpannya sebagai laporan inspeksi.
  • Menampilkan statistik, peta, dan riwayat inspeksi kepada pengguna yang sudah masuk.
  • Menjaga keamanan layanan, misalnya mencegah penebakan kata sandi dan pembuatan akun palsu.

Kami tidak menjual data Anda dan tidak memakainya untuk iklan.

3. Siapa yang dapat melihat data

Laporan inspeksi (foto, lokasi, waktu, dan hasil analisis) dapat dilihat oleh seluruh pengguna RoadPulse yang sudah masuk, karena tujuan aplikasi adalah memetakan kondisi jalan bersama. Username Anda tidak ditampilkan pada laporan. Administrator dapat mengubah atau menghapus laporan dan akun.

4. Layanan pihak ketiga

  • OpenStreetMap untuk menampilkan peta, dan Nominatim (OpenStreetMap) untuk mengubah koordinat menjadi nama jalan pada dashboard web. Koordinat dikirim ke layanan ini saat nama lokasi dicari.
  • Aplikasi mobile memakai layanan lokasi bawaan perangkat (Android/iOS) untuk mencari nama jalan.

5. Penyimpanan dan keamanan

Data disimpan di server RoadPulse dan dikirim melalui koneksi terenkripsi (HTTPS). Akses ke data inspeksi memerlukan login. Laporan disimpan selama masih dibutuhkan untuk pemantauan jalan, atau sampai dihapus atas permintaan Anda.

6. Hak Anda

Anda berhak meminta salinan data Anda, memperbaiki data yang keliru, menghapus akun beserta laporan yang Anda kirim, serta menarik izin kamera dan lokasi kapan saja melalui pengaturan perangkat.
