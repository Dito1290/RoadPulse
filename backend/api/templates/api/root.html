BACKEND AKTIF · API VERSI 1

Data kondisi jalan, terhubung.

Backend RoadPulse menerima foto inspeksi, menjalankan klasifikasi, dan menyediakan statistik, riwayat, serta titik lokasi untuk dashboard.

Lihat statistik API

Endpoint tersedia

Endpoint GET dapat dibuka langsung. Endpoint POST menerima data dari aplikasi.

POST /api/v1/classify/

Klasifikasi gambar

Unggah foto jalan untuk mendapatkan label kerusakan dan skor keyakinan.

GET /api/v1/dashboard/stats/

Statistik dashboard

Jumlah inspeksi, distribusi kelas, dan data inspeksi terbaru.

GET /api/v1/dashboard/history/

Riwayat inspeksi

Daftar inspeksi dengan paginasi untuk tabel dashboard.

GET /api/v1/dashboard/map/

Data peta

Inspeksi yang memiliki koordinat GPS untuk ditampilkan pada peta.

POST /api/v1/auth/login/

Autentikasi

Masuk menggunakan username dan kata sandi untuk memperoleh token API.

Dokumentasi API: gunakan Swagger UI untuk mencoba request, ReDoc untuk membaca dokumentasi, atau OpenAPI JSON untuk mengunduh schema.

Ingin membuka dashboard visual? Jalankan frontend dari folder frontend dengan python -m http.server 3000, lalu buka http://localhost:3000. Halaman ini adalah portal API backend.
